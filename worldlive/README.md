# WorldLive Android

Standalone Android app for opening public live webcam/video feeds directly from providers. No app backend is required.

## Features
- Built-in public live feed shortcuts
- In-app web/YouTube feed playback
- Direct HLS/MP4/RTSP playback using AndroidX Media3
- Add and remove custom stream URLs
- Custom streams stored locally on the device
- No login and no WorldLive server

Only use streams that are public or that you have permission to view.
